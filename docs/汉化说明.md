# 汉化说明 / Localization Guide

> 蔚蓝档案 格斗游戏 简体中文汉化版 —— 说明文档 Blue Archive Fighting Game (Tentative) — Simplified Chinese Localization

文档版本：v1.0
汉化对象：https://github.com/mattsumi/blue-archive-fighting-game
上游版本：main 分支，2026-11-02 快照（提交 988798bd4facd5307ba7efc63ff6e0055924a25b）
引擎版本：Godot 4.7.2 stable（未升级、未降级）
项目目录：（仓库根目录）
默认语言：简体中文

## 这份汉化做了什么

1. 全量界面文本汉化
   主菜单、角色选择、助战选择、地图选择、VS 画面、战斗 HUD、暂停菜单、
   结算画面、设置（含按键说明）、额外内容（角色图鉴 / 音乐播放器 / 战绩记录）、
   制作人员名单、标题画面底部署名，全部改为简体中文。

2. 战斗特效图像字汉化
   游戏里的大号美术字（FIGHT / START / WIN / LOSE / ROUND N / K.O. / TIME UP /
   WARNING / BLOCK / MISS / COMBO / EX READY / JUST GUARD …）原本是 PNG 图片，
   不是文字。汉化版另外烘焙了一套等尺寸的中文图片字，存在
   assets/ba/hud/words_zh/ 里，中文模式下自动替换，英文模式下仍用原图。

3. 中文字体接入
   新增 Noto Sans SC（思源黑体 Google 发行版，SIL OFL 1.1）6 个字重，
   以「回退字体（fallback）」方式挂在原有拉丁字体后面：
   英文、数字、符号仍然用原来的 Barlow Condensed / Chakra Petch / Noto Sans，
   只有中文才由 Noto Sans SC 出字。这样既保证了中文不缺字，也最大限度保留了
   原版 UI 的字形气质与排版节奏。

4. 排版适配
   * 文字量测（text_width / fit / clip）全部改为量「翻译后的字符串」，
     所以按钮、色带、铭牌会按中文的实际宽度收放，不会按英文宽度算好再溢出。
   * 中文没有空格，原版的按空格换行对中文无效。新增了按字断行 + 基本禁则
     （行首不出现 ，。、！？」』），角色简介、制作人员说明等长段落已正常折行。
   * 字体按实际用字裁剪（1149 个字符），6 个字重合计从 60MB 压到 2.2MB，
     画面效果不变。

5. 语言切换
   设置 → 语言 一行可在「简体中文 / English」之间切换，即时生效并写入
   存档配置（settings.cfg 的 [ui] language）。英文模式下所有界面回到原版英文，
   英文原文完整保留在代码里，没有删除、没有改写。

6. 汉化团队署名
   制作人员名单末尾新增「简体中文汉化 / SIMPLIFIED CHINESE LOCALIZATION」
   栏目，署名 Motu Game Tech（冇圡游戏科技）与 7 项汉化贡献。
   中文界面显示中英双语的团队名，英文界面只显示 Motu Game Tech。

7. Windows 平台修复（必要修复，非汉化内容）
   原仓库里 assets/glyphs/*/aux.png 用的是 Windows 保留设备名 AUX，
   Windows 上 git clone 会报 invalid path，Godot 也读不到该文件，
   导致「设置 → 按键图标」页面直接报错。汉化版把文件改名为 aux_.png，
   并在 scripts/ui/controller_glyphs.gd 里做了兼容读取（先试原文件名，
   再试 aux_.png，Linux/macOS 上行为不变）。这是让项目能在 Windows 上
   正常跑起来的前提。

## 汉化是怎么实现的（技术结构）

核心思路：不去逐个改写 40,873 行脚本里的英文，而是「英文原样留在代码里，
译文单独放一张表」，在绘制层统一查表。

新增文件
  assets/locale/zh_cn.json   英文 → 中文 对照表（791 条），纯 JSON，可读可 diff
  scripts/core/loc.gd        自动加载单例 Loc，负责查表、切换语言、统计漏译

挂接点（这些位置统一调用 Loc.t()，所以调用方一行都不用改）
  scripts/ui/ba_menu.gd      label() / text_width() / fit() / clip() / ribbon()
  scripts/ui/ui.gd           label()（Label 节点）、字体与中文回退
  scripts/ui/gallery_kit.gd  draw_name() / wrap_text()（按字断行）
  scripts/fight/hud_kit.gd   text() / width()
  scripts/ui/ba_words.gd     图像字：中文模式下优先取 words_zh/ 的图

另外对少量「直接 draw_string / 直接赋 Label.text / 带 %d 拼接」的位置
做了定点处理：VS 画面、地图选择、暂停菜单、角色图鉴招式表、
训练模式提示、结算、战斗特效飘字等。

查表规则
  Loc.t("Story")            → "剧情"
  表里没有的字符串           → 原样返回（绝不会出现空白，最差就是保留英文）
  全大写查表（DAMAGE 等）    → 会自动做一次大小写归一，兼容代码里的 to_upper()
  已经是中文的字符串         → 直接返回，不再重复查表

数据层
  角色名、学校、社团、EX 技能名等来自 assets/ba/roster.json，
  汉化版没有改动这个文件，而是在对照表里补了对应条目，
  所以原始数据文件保持上游原样。

## 怎么运行

### 方式一：直接玩（推荐）

  双击 BlueArchiveFightingGame-Chinese\export\windows\BlueArchiveFightingGame.exe

  这是一个单文件程序（已内嵌 .pck），不需要安装，不需要额外的 DLL。
  系统要求：Windows 10/11 64 位，显卡支持 Vulkan 1.0（或 DirectX 12）。
  首次启动约 3~8 秒（要在内存里展开 300MB 资源）。

### 方式二：用 Godot 编辑器打开源码

  1. 用 Godot 4.7.2 stable 打开项目目录（含 project.godot 的那一层）
  2. 首次打开会自动导入约 2600 个资源，需要 2~4 分钟，请耐心等待
  3. F5 运行

### 方式三：命令行跑无头自检

  Godot_v4.7.2-stable_win64_console.exe --headless --path . --quit-after 180

## 怎么继续修改译文

1. 改译文
   直接编辑 assets/locale/zh_cn.json，格式：

       "Story": "剧情",
       "Versus 2P": "双人对战",

   左边是代码里的英文原文（必须一字不差，包括空格和标点），
   右边是中文。改完保存，重新运行游戏即可生效，不需要重新导入。

2. 找漏译
   汉化版带了一个漏译统计：运行游戏时加上参数

       --dump-missing=漏译输出路径.txt

   游戏退出时会把本次运行中「查表没查到」的英文字符串写成一行一条。
   再用工具对比：

       python tools/loc_coverage.py 漏译输出路径.txt

   会列出还差哪些条目。当前版本的漏译清单见《汉化完成度报告.txt》。

3. 改图像字
   战斗里的大号美术字由 tools/make_zh_words.py 生成：

       python tools/make_zh_words.py

   脚本会读 assets/ba/hud/index.json 里每个词的原始像素尺寸，
   按同样尺寸重新生成中文图，写进 assets/ba/hud/words_zh/。
   想改某个词的中文，改脚本顶部的 WORDS 字典，重跑即可。

4. 重新裁剪字体（只有增删了大量新字才需要）
   node tools/subset_fonts.cjs .

   注意：裁剪后的字体只包含当前译文用到的字。如果新加的译文里出现
   生僻字，必须先跑这一步，否则会显示成方框。

5. 校验字体是否覆盖全部译文用字（改过译文后建议跑一次）
   Godot_v4.7.2-stable_win64_console.exe --headless --path . \
       --script res://tools/check_glyphs.gd
   输出 TOTAL MISSING GLYPHS: 0 即为全部有字。

6. 重新导出
   Godot_v4.7.2-stable_win64_console.exe --headless --path . \
       --export-release "Windows Desktop" export/windows/BlueArchiveFightingGame.exe

## 没动过的东西（重要）

按任务书第六阶段要求，以下内容全部保持上游原样，一行未改：

  * 战斗数值（伤害、血量、硬直、帧数据）——脚本未触碰
  * 攻击判定（hitbox / hurtbox / 判定框）——未触碰
  * 角色动作、动画、骨骼、模型——未触碰
  * AI 行为（cpu_brain.gd 及其难度）——未触碰
  * 物理系统、时间步进——未触碰
  * 游戏模式（双人 / 人机 / 单人 / 训练 / 额外内容）——全部保留
  * 存档格式（settings.cfg / records）——只新增了 [ui] language 一项，
    旧存档可以直接读，不会失效
  * Godot 引擎版本——仍是 4.7（用 4.7.2 stable，与项目声明一致）

git 仓库里可以逐行核对（git diff upstream zh-cn）：
  upstream 分支 = 上游原样（提交 9b2f032 "upstream … (pristine)"）
  zh-cn    分支 = 汉化版（当前分支）

  两个分支的差异即全部汉化改动，可 git diff upstream zh-cn 逐行查看。

## 已知限制

1. 标题 LOGO「Blue Archive Fighting Game」是位图美术，没有改。
   这是游戏自己的标题字（品牌标识），替换会破坏原画风格，故保留。
2. 3D 地图里的贴图文字（例如格黑娜地图的 "DO NOT ENTER" / "ROAD CLOSED"
   路牌）烘焙在模型贴图里，属于美术资源，未改。
3. 招式表里的 5L / 5H / 2L / 2H / jL / jH 是格斗游戏通用帧表记号，
   官方中文版同样保留英文记号，故不翻译。
4. 语音（角色台词）仍是日语音源（上游素材如此），中文字幕已汉化。
5. 网络对战 / 剧情模式本身在上游就是 Coming Soon，未新增功能。

详见《未汉化内容及原因.txt》。
