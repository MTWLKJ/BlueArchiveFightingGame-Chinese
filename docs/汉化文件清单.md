## 重命名文件（Windows 保留设备名修复）

原路径 → 新路径（内容完全一致，未做任何图像修改）：

  assets/glyphs/playstation/aux.png → aux_.png
  assets/glyphs/steam/aux.png       → aux_.png
  assets/glyphs/steamdeck/aux.png   → aux_.png
  assets/glyphs/switch/aux.png      → aux_.png
  assets/glyphs/xbox/aux.png        → aux_.png

（对应的 aux.png.import 一并改名，由 Godot 重新生成）

原因：AUX 是 Windows 保留设备名。原仓库在 Windows 上
  ① git clone 直接报 "invalid path"；② 即使文件存在，Godot 也读不到；
  ③ 读到空指针后「设置 → 按键图标」会刷屏报错并退出。
  代码侧已做兼容：先试原名，再试 aux_.png，Linux/macOS 行为不受影响。
