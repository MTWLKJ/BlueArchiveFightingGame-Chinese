# 未汉化内容及原因 / Not Localized, and Why

> 未汉化内容及原因

本文件诚实列出「可见但未汉化」与「有意保留英文」的全部内容，
以及每一类的具体路径与理由。除此之外，界面文本没有遗漏。

## 有意保留（属于品牌 / 专有名词 / 通用记号）

1. 标题 LOGO「Blue Archive Fighting Game」
   路径：assets/ba/title/（位图美术字 + 标题影片）
   原因：这是游戏自己的标题字，属于品牌标识。它是烘焙进图片/影片的位图，
         重绘会破坏原版美术风格，也会改变读取该区块的整套版式。
         目标书第五阶段要求「优先寻找原始可编辑资源，在不破坏原版画风
         的前提下替换」——本项目没有提供该 LOGO 的可编辑源文件，
         因此按「无法安全修改则记录路径与原因」处理。
   影响：仅标题画面正中一处。

2. 官方英文专辑名与曲名
   路径：assets/ba/jukebox/albums.json、scripts/core/stages.gd（曲名常量）
   例：Blue Archive Original Soundtrack Vol.1、"Constant Moderato"、
       "Unwelcome School"、"Step of Terror"
   原因：这些是官方发行的原声带专辑名与曲名，属于专有名词。
         《蔚蓝档案》简中官方版本同样保留英文曲名，翻译反而会破坏可检索性。

3. 格斗游戏帧表记号
   路径：scripts/ui/gallery_characters.gd
   内容：5L / 5H / 2L / 2H / jL / jH 以及 MG / SG / SR / GL 等武器缩写
   原因：格斗游戏通用记号，行业与玩家社群均直接使用英文记号，
         官方中文版亦不翻译。译成中文反而增加理解成本。

4. 必要英文缩写
   内容：EX、CPU、HUD、BGM、SFX、K.O.、VS
   原因：目标书第四阶段明确要求「保留必要的英文缩写」。
         VS、K.O. 同时是美术字（保留原图）。

5. 角色身高数值与百分比
   内容：142cm、145cm、70%、80%
   原因：数字与单位不需要翻译；计量单位在中日语境下写法一致。

6. 网络地址
   内容：bluearchive.nexon.com、x.com/en_BlueArchive、
         www.youtube.com/channel/...、discord.com/invite/...、
         www.facebook.com/EN.BlueArchive、github.com/mattsumi
         （以及制作人员里指向工具与字体的 GitHub 链接）
   原因：URL 不能翻译。链接标题（「官方网站」「蔚蓝档案 X（推特）」等）
         已全部汉化。

7. 声优姓名
   内容：广桥凉（Ryō Hirohashi）、花守由美里（Yumiri Hanamori）
   说明：已按简中习惯改为汉字。其余角色的声优字段上游数据本身为
         Latin 拼写，本版保留原样。

## 技术上无法安全修改（美术资源内的烘焙文字）

1. 3D 地图贴图里的英文
   路径：assets/ba/stages/gehennaslum/*.glb 及 *.dds / *.png 贴图
   例：地图中的 "DO NOT ENTER" 路牌、"ROAD CLOSED" 路牌、
       集装箱上的 "07" 编号等
   原因：这些文字烘焙在 3D 场景的贴图里，属于美术资源而非 UI 文本。
         直接改贴图需要重建 UV 与材质，属于「破坏原版画风」的高风险改动，
         且上游没有提供可编辑的分层源文件。
   影响：仅战斗场景内的装饰性路牌，不影响任何功能与可读信息。

2. BA 官方 HUD 精灵图内的文字
   路径：assets/ba/hud/sprites/、assets/ba/hud/tex/
   例：Combat__Combat_Time_Icon（时钟图标）等装饰性图形
   说明：这些图形本身不含成句英文，只是图标装饰，无需处理。
         真正含英文单词的 HUD 美术字（FIGHT / WIN 等）已全部重制中文版
         （见汉化完成度报告第二节）。

## 上游本身即为日文/自有的素材

1. 角色语音
   路径：assets/audio/ba/menu_voice/*.ogg
   内容：日语音源
   原因：语音是原声素材，汉化不做配音。对应的中文字幕已全部汉化
         （主菜单 25 条台词）。

2. 标题影片（.ogv）
   路径：assets/ba/title/video/*.ogv
   内容：《蔚蓝档案》官方片头影片
   原因：影片是官方素材，内含日文/英文画面。替换影片即篡改官方素材，
         且会破坏片头节奏。保留原样。

## 非玩家可见（开发者工具，不在游戏流程内）

以下页面/文本只存在于开发者调试路径，玩家在正常游玩中无法到达，
本版未汉化（保留英文以免影响上游调试工具的可读性）：

  scripts/core/dbg.gd                 调试命令回显
  scripts/models/sd_preview_screen.gd SD 动画预览工具（不计入菜单）
  scripts/fight/movesets.gd           招式设计的英文注释与判定说明
  scripts/fight/kits/*.gd             角色招式实现里的英文注释
  scripts/fight/tests/*.gd            自动化测试
  scripts/ui/tests/*.gd               美术比对测试
  tools/*.py, tools/*.sh              构建与资源处理工具

  说明：其中的 push_error / push_warning 报错信息同样保留英文。
       这些信息只输出到控制台，玩家在正常游玩中看不到。
       如需汉化，可在 zh_cn.json 里补条目，机制与界面文本完全一致。

## 上游功能本身尚未实现

1. 剧情模式（Story）
2. 网络对战（Network）
   两者的磁贴在上游就是灰色的「COMING SOON」，点选只弹出提示，
   没有可进入的界面。本版保持原状，仅把提示汉化为「敬请期待」。
   未新增任何功能——目标书第六阶段要求不得删除原版游戏模式，
   本版同样不新增模式。

## 复查方法（如何确认这份清单是完整的）

  1. 运行游戏时加参数收集漏译：
       Godot_v4.7.2-stable_win64_console.exe --path . \
         -- --dump-missing=missing.txt
  2. 走一遍全部界面后退出，得到 missing.txt
  3. 比对：
       python tools/loc_coverage.py missing.txt
  4. 输出中若出现本文件未列出的条目，即为遗漏，请补进 zh_cn.json。

  当前版本第 3 步的输出共 40 类字符串，
  全部落在本文件第一节（保留项）与第四节（不可见）范围内。
